## Babelstårnet 0.2

This release adds a private local learning profile, mixed Danish/English
beginner explanations, explicit **Knew** and **Don’t know** feedback, temporary
idle holding, keyboard controls, profile import/export, clearer English-word
outlines, translation recovery, and lower-power screen reading.

### Downloads

- **DMG:** the normal drag-to-Applications package.
- **APP ZIP:** a direct ZIP containing `Babelstaarnet.app`, provided for Macs
  where the unsigned DMG workflow is inconvenient.

This preview is ad-hoc signed because the project does not yet have an Apple
Developer ID. macOS may say it cannot verify the developer. After extracting
or installing the app, Control-click **Babelstaarnet.app**, choose **Open**, and
confirm once. All OCR, translation, explanations, speech, and learning-profile
data are processed and stored locally.
