# 学习与新内容推荐决策 Policy v1

状态：v1 已接入两端客户端；产品约束与当前边界见下表。更新：2026-10-24。

本文件把学习设计收敛为可实现的决策规则。适用于 macOS 与 Windows；
平台只负责窗口、系统通知和网络适配。现有行为以
[How it works](HOW_IT_WORKS.md) 为背景，本文明确列出的变更以本文为准，
后续扩展也必须遵守这些约束。

对应的设计输入/预期输出见 [policy cases](learning-policy-cases.json)。这些例子不等同于自动测试覆盖。
运行时共同用例在 `Tests/Shared/policy-runtime.json`，阅读行为例子在
`Tests/Shared/reading-contract.json`；两端测试执行同一份 C 原生规则。文中的“必须”是产品约束；
标为“试验参数”的数字可调整，不能解释为已经验证的认知学阈值。

## 本次实现范围

| 范围 | 当前行为 |
| --- | --- |
| 阅读 | 主动查词始终给出完整可用释义；句卡可主动请求整句意思，默认快捷键 4；自然融入/充分辅助模式保存到本机 |
| 轻量回想 | 仅非焦点、曾主动学习、等级 3 且现有释义与已保存释义一致的词；每句 1 个、每次阅读会话最多 3 个单位。10 分钟内两次求助后，该会话不再额外挑战此词；已有帮助不撤回 |
| 证据 | 现有 Level 和档案继续使用；新增可选的 evidence kind，认识/复习仍为用户自报，不冒充盲答证据；未实现新的听力、产出或测验引擎 |
| 新闻 | 默认关闭；DR 官方 RSS 标题、时间、链接及来源实际提供的摘要。主题选择、本地最近 14 天词形匹配、近重复去重、已看反馈、每组至多 3 条、页签记忆 |
| 排序边界 | 主题是用户主动选择的来源过滤器；兴趣和可读性尚无校准模型，均取未知值 0.5。匹配只按原始标题/摘要的词形计低权重，不声称确认义项复习；没有屏幕兴趣画像、同事件新进展判定或多看/少看学习器 |
| 本机 AI | 点击后才使用已安装模型简化 RSS 原摘要；原摘要保留并标注 AI 和模型版本。数字、大写实体、否定/归属标记和引号做保守比对，非事实正确性证明。不抓取/改写完整新闻正文 |
| 联网/提醒 | 前台、后台刷新、每日摘要分别授权；关闭新闻同时关闭后台及通知。只在应用运行且未阅读、未打开新闻页、系统允许通知时，在选定 09–20 点时段至多提醒一次，已通知标题不再推送 |
| 故障与优先级 | 抓取有大小/时间/频率上限及指数退避；新闻生成单任务、90 秒期限，阅读期间不启动，开始阅读即取消新闻生成。失败保留原摘要和离线功能 |

语境词义变化只是增加帮助的保守信号，不建立新的可靠义项模型，也不重置整词档案。
推荐列表优先展示最近 48 小时，不足 3 条时扩展到 7 天；旧缓存不作为新消息展示。
缓存有条目/文件大小上限，磁盘缓存可保留到下一次更新，不将此描述为定时删除保证。

## 0.6.2：丹麦语承担阅读，英文只填空缺

0.6.1 默认并列显示完整英文的决定作废：它让用户绕过丹麦语，违背产品目的。
两端使用同一原生规则：新闻正文以丹麦语呈现，陌生或尚不稳定的词（等级 0–3）
在词下方获得简短英文锚点；稳定熟词（等级 4–5）保留丹麦语，不显示自动释义。
同文译词不重复显示；词典或单词翻译不冒充可靠的语境义项。不向学习中的词
额外出题。原文始终可直接选择，提供完整可用词义、显式朗读和保存到同一生词本。

完整英文只在主动点击 **Help with this sentence** 后出现，只影响当前卡片；
**Back to Danish** 立即收起。请求没有猜题、等待或次数限制，不降低整词熟悉度。
关闭阅读页后恢复丹麦语；旧版 English support 开启偏好也不能恢复默认完整英文。
不在用户阅读时撤走已显示锚点；学习档案变化在下一次访问时生效。
浏览、查词、整句求助或保存新闻单词均不自动提高或重置掌握度。

生词本是塔形菜单中的主要入口，不依赖设置页或屏幕读取权限。
Mac 同时提供应用菜单与 ⇧⌘B。设置只管理偏好和档案，不承担日常阅读导航。

完整英文与原始文本指纹、单词锚点分别有界缓存在 `news-reading.json`。关闭新闻联网后，
已缓存标题仍可得到离线翻译；没有翻译资源时给出明确设置提示，不切云服务。
Mac 的系统路径先确认语言包已安装；阅读页不请求隐式下载。后台刷新和通知
设置保留在设置页，不占据主要阅读区域。可选本机 AI 也可简化只有标题的条目，
只处理来源实际提供的 RSS 文本，继续保留原始内容和保守检查。

## 1. 产品决策

### 0.6.3：状态栏一级入口与自愿开启的新闻小窗

点击状态栏/托盘塔形图标直接打开原生菜单，一级依次提供生词本、读点新的、
定时新闻卡设置。生词本直接进入词条页，不依赖设置或屏幕读取权限。

定时小窗是独立、默认关闭的授权，不继承旧版“每日摘要”的通知授权。
需要新闻联网和后台刷新同时开启；用户可选每 1、2、4 小时，默认 2 小时。
开启后等待一个完整间隔；09:00–21:00 展示，每个本地自然日最多三张。
首次开启不立即弹出，重启不重置间隔、次数或已展示新闻记录。
错过的时段不积压补弹；过去 48 小时内的新候选不足就少展示。

小窗只能展示本地模型已生成并通过现有保守检查的丹麦语改编文本。
没有模型或改编失败时保留生词本原文，显示明确状态，不冒充已经改编。
只改写来源实际提供的 RSS 摘要，缺摘要时改写标题；不抓取完整正文。
小窗标注 DR、联网来源、本机改编，并保留原始标题和本地模型身份。
丹麦语、陌生词锚点、主动整句求助继续遵守 0.6.2 决策，不默认并列完整英文。

忙碌的屏幕阅读优先；检测因无输入暂停时才允许本地生成，恢复阅读即取消生成。
新闻页或已有小窗打开时不再主动弹出，锁屏/休眠时不展示；Windows 还检查系统
是否接受通知。小窗不抢焦点、不自动播放声音，不把展示、关闭或保存当成掌握证据。
用户停留在小窗时保持显示，离开后 45 秒收起。提供关闭、今天暂停和关闭功能；
设置可恢复暂停，并可主动“立即试一张”，不偷偷开启定时展示。
关闭新闻/后台刷新撤销定时展示；关闭发生后，迟到的模型结果也不能再弹出。
旧的每日标题通知保留为替代选项，与定时卡片互斥。

用户的主要任务是理解自己关心的信息。学习利用阅读机会发生；不能要求用户
先完成一道学习任务，才允许得到翻译或继续阅读。

联网授权、来源能力和答案可靠性是硬门槛。在门槛内，优先级固定为：
明确的用户操作 > 响应速度与阅读连贯性 > 内容兴趣与新信息 > 额外练习收益。

本轮修订：

| 之前的想法 | 决策 | 原因与替代 |
| --- | --- | --- |
| 默认邀请重读上周的旧句 | 移出默认流程 | 重复内容缺少信息收益；旧句只在用户点“上次那句”时作为记忆线索 |
| 熟悉词的释义先藏起来，让用户回想 | 限于句子中的非焦点词 | 主动悬停已经是求助，焦点词必须立即得到完整答案 |
| 打开生词本先做一题 | 取消前置题 | 生词本首先完成查找、管理和阅读；练习保留独立入口 |
| 每次遇到学习词都制造一点困难 | 设置上限和冷却 | 避免频繁操作把用户推向整页翻译 |
| 以复习匹配率决定推荐内容 | 降为相关候选的排序因素 | 无聊的新闻不会因为出现三个熟词就变得值得读 |
| 帮助按钮意味着学习退步 | 取消此推断 | 查看词义、确认另一义项、理解语法是不同需求 |
| 只有混合语言桥接，缺少整句兜底 | 增加主动请求的整句释义 | 用户可能认识单词却不理解句子；应在本工具内解决 |

## 2. 统一输入与证据

### 2.1 决策输入

- `action`：主动查词、看整句意思、查看线索、主动练习、打开新闻页、刷新、
  请求短版、开启/关闭联网、开启/关闭通知等明确动作。
- `readingMode`：`natural`（默认，自然融入）或 `supported`（充分辅助）。
  由用户选择并保存；不能按日历或“完成目标”偷偷恢复挑战。
- `sessionId`：一次开始阅读到停止阅读之间的会话；新闻页浏览不自动开启阅读。
- `unit`：词元、可靠识别的义项或词组、当前词形、上下文标识。
- `evidence`：接触时间、是否看过答案、求助、用户自报、盲答结果、提示使用、
  不同日期/上下文的历史。缺失表示未知。
- `quality`：OCR/文本提取是否可用、语境义项是否有可靠支持。模型自报的
  confidence 不能独立证明可靠性。
- `readingActive`、本地引擎状态、可安全抢占能力、缓存状态。
- 新闻授权、刷新偏好、通知偏好、用户选择的主题、新闻来源能力与发布时间。

### 2.2 证据类型（LEARN-01）

| 事件 | 可以记录 | 不能推断 |
| --- | --- | --- |
| 出现在已识别句子中、重复悬停 | 接触/查看 | 用户确实读过、理解或掌握 |
| 请求释义、请求整句解释 | 本次需要帮助 | 全词遗忘、句中所有词都不会 |
| 点“认识”、脑中默答后点“想到了” | 用户自报 | 经验证的无提示提取 |
| 可核对答案的盲答正确 | 指定方向、义项和提示条件下的提取证据 | 所有义项、听说读写都已掌握 |
| 新闻卡片打开、滚到末尾 | 打开/到达末尾 | 读懂、完成学习、记住匹配词 |
| 未点释义、很快离开 | 无明确理解证据 | 识别成功或失败 |

保留现有学习档案，不能把历史 Level 自动改名为“经验证掌握”。后续扩展采用
带版本的附加证据；导入旧档案缺失的方向/义项证据保持未知。

“会读含义”“能听懂”“能从含义想起丹麦语”分别记录。提示后答对单独记录。
词形继承可以帮助选择辅助量，但不能把新义项或新词组直接视为已掌握（LEARN-02）。

## 3. 阅读决策

### UX-01：主动求助立即回答

主动悬停/查词时，焦点词始终显示可用的完整语境释义，不受学习等级影响。
先显示已有的本地答案；后续语境结果按现有稳定呈现规则补充。
不增加教学等待、限次、先猜再看或“你应该会了”提示。
没有可靠答案时说明状态，允许进一步求助，不能展示一道题填补等待。

### UX-02：提供“看整句意思”兜底

词卡或句卡提供稳定可发现的轻量入口，支持键盘，使用本地翻译。
它输出尽可能自然的整句含义，与保留丹麦语词序的混合句子明确区分。
用户可切回原文/桥接；一次请求不永久更改阅读模式。

请求整句释义只记录 `sentence_help`，不批量降低词汇熟悉度。
当前缺少可用引擎或答案时明确说明；不能自动切到云翻译。

此规则有意修订 HOW_IT_WORKS 中“整句翻译入口被移除”的旧决定。
桥接不能处理所有语法和习语理解问题，缺少兜底会增加切换外部工具的成本。

### UX-03：学习发生在非焦点词上

默认桥接继续保留稳定熟悉的丹麦语，给陌生词必要的英文锚点。
仅当 `natural` 模式、文本可靠、词义明确、存在此前实际学习事件，且上下文
可提供线索时，才允许把一个尚不稳定的非焦点词保留原文作为回想机会。

试验参数：每句最多 1 个这样的薄弱词，同时重点巩固最多 3 个单位。
这些上限不限制自然保留的稳定熟词，也不限制主动求助。
首次遇到的词、陌生义项、拿不准的词组不承担挑战。
不插空、不故意降低文字对比度、不把正文打码。

同一冻结阅读片段中的辅助决策保持稳定。用户主动求助可以立即增加帮助；
模型完成或学习分数变化不能在阅读中突然收走已经显示的帮助。

### UX-04：求助后退让

`supported` 模式不给薄弱词额外挑战；稳定熟词仍可自然保留，陌生/学习中的词
得到锚点。模式可以随时切换，文案为“充分辅助”，不称“偷懒/跳过学习”。

同一学习单位在同一会话 10 分钟内两次主动求助后，停止对它制造额外挑战，
直到会话结束（试验参数）。一次求助也必须立即回答；冷却只影响后续呈现，
不阻止求助。不把冷却解释为疲劳诊断或全词遗忘。

### LEARN-03：自然复现，不制造任务债

只有在用户自然再次遇到内容时，才用到期状态选择薄弱词；没有相遇就不打断。
同一片段重复悬停只算查看，不能快速累计掌握。
旧句提示只在用户请求时出现，不作为默认新闻、通知或生词本首屏任务。

主动补全、先听后看、跟读属于独立练习入口，默认没有前置题或自动播放练习。
可以忽略它们而完整使用阅读、查词、生词本和新闻功能。

## 4. “读点新的”新闻推荐

### NEWS-01：入口与动机

生词本保留“词条”与“练习”，新增可选的“读点新的”页。
新闻关闭且无缓存时，入口只显示静态说明和开启动作，不访问来源；
有未过期缓存时仍可进入“已缓存内容”，不自动更新。
开启后记住用户自己选过的页签，不强制把词条管理首页改成新闻。

一组默认最多 3 张卡片，可点“换一组”；不采用自动无限滚动。
卡片先呈现真实标题、来源、原始发布时间和短摘要，再呈现学习相关性。
“包含你最近接触的词”只能依据实际取得的标题/摘要/正文标注对应范围；
不能因主题相关就声称正文出现某个词。

用户得到的首先是新消息，词汇复现是阅读这条消息带来的额外价值。
已展示的一组卡片保持稳定；后台更新只显示“有新内容”入口，
由用户刷新或换组后更新列表，不能在点击前自动改排序。

### NEWS-02：候选资格先于学习匹配

按顺序执行，任一硬门槛不满足就跳过：

1. 来源适配器经过核实，字段取得与展示方式在其已确认的能力范围内。
2. 标题、原始发布时间、原文链接可用；日期无法确认时不放入“最新”。
3. 用户未屏蔽，且符合其选择的主题；无主题偏好时使用一般新闻候选。
4. 去重后存在实质新信息，不是改标题、同事件复刻、旧闻重新抓取。
5. 内容适合当前展示方式；仅拿到摘要时按摘要推荐，不假装已读全文。

试验参数：优先最近 48 小时；不足时可扩到 7 天并保留明确日期。
没有合适的新内容就少展示，不用旧练习材料补满。
同一事件 7 天内最多一张卡；已看事件出现可确认的新进展可以标“新进展”
重新进入候选。仅更新时间变化不构成新进展。
无法可靠聚类时至少合并规范 URL、标题近重复和内容指纹；无法确认新进展
的已见事件保持隐藏，用户可从历史主动找回。

### NEWS-03：本地排序

仅对合格候选排序。各项归一到 0..1，首版试验分数为：

`0.35 × 兴趣匹配 + 0.30 × 新鲜度 + 0.20 × 学习相关性 + 0.15 × 可读性`

- 兴趣来自用户选题及本功能内的“多看/少看”，不对屏幕截图建立兴趣画像。
- 新鲜度按原始发布时间及确认的新进展计算，不能用抓取时间冒充。
- 学习相关性只使用最近 14 天有主动保存、标记或练习事件的实词/词组。
  上限 200 个候选单位（试验参数）；排除 `og`、`er` 等高频结构词和纯人名匹配。
  匹配在本地做，优先可靠的同义项/词形/词组。只有字形匹配时降低权重，
  不把它算作义项复习。自动接触记录不等于“已学会”。
- 可读性使用实际可见文本长度、辅助需求和句法负担的保守估计；不宣称
  “认识百分之多少就必然读懂”，也不为覆盖率强行改写事实。

分数输入需要标注估计器版本，未知值取 0.5，不能把模型的自信直接当分数。
首版兴趣分为明确匹配 1、无偏好 0.5；被明确排除的主题在资格阶段删除。
新鲜度为 `max(0, 1 - ageHours / 168)`，时钟统一用 UTC，展示转换为用户时区。
学习分为 `min(1, weightedMatches / 2)`：可靠的同义项/词组命中权重 1，
可靠同义项的词形继承 0.7，仅字形且义项不明 0.25，结构词或人名 0。
同一学习单位重复出现只计一次。首版未有共同校准的可读性估计器时统一取 0.5，
先用真实篇幅帮助用户选择；加入估计器时升级策略版本与两端共同用例。

并列时按原始发布时间、稳定的 articleId 排序。每组同一事件最多一张；
有多主题候选时，同一主题最多两张。允许无学习词匹配的新内容入选。
符合兴趣但较难的新闻可提供完整辅助，不因难度永久隐藏。

没有匹配时显示普通新内容或“暂无合适的新内容”，不把熟词硬塞进新闻。
学习匹配依据来源实际文本计算；改写中新加入的目标词不能回流提高推荐分数，
否则系统会通过反复改写制造虚假的相关性。
用户点“已看过”只影响内容去重，不增加词汇掌握。

### NEWS-04：配送方式与通知

默认仅在生词本新闻页内展示。开启新闻不等于允许后台刷新或系统通知。

可单独开启“每日新闻摘要”：首版最多每天一次、最多三条，只有新候选才发送。
通知使用真实新闻标题，避免“还有 8 个词没复习”“别让进度归零”等催促文案。
仅词汇到期、旧文重新匹配、后台重新排序不触发通知。

首版试验时段为本地 18:00，可调整；21:00–09:00 为默认免打扰时段。
正在阅读、系统免打扰、用户设置的静默时段或已达当日上限时不发送；
本次摘要可留在新闻页，不在稍后集中补发错过的通知。

仅允许应用运行且相应权限具备时调度；没有后台能力的平台不承诺退出后推送。
两端遵循相同的额度、时区和抑制规则，各自使用原生通知。
额度与去重记录留在本机，不承诺跨设备合并通知次数。

## 5. 联网边界与开关

### NET-01：默认关闭、独立授权

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 新闻推荐（联网） | 关闭 | 允许本功能从已核实来源获取公共新闻 |
| 后台刷新 | 关闭 | 新闻页不在前台时也可刷新公共条目 |
| 每日新闻摘要通知 | 关闭 | 单独申请系统通知并设置时段；也需要后台刷新开启 |
| 本机短版改写 | 按需 | 只有点“读短版”才运行；可关闭，不自动下载模型 |

新闻关闭时，本功能的 HTTP 请求数必须为零，包括标题、远程图片、图标、
字体、埋点和“检查是否有新内容”。原有离线阅读与朗读继续独立工作。
开启新闻不改变截图、识别文本、词表、学习记录的本地处理边界。

主开关关闭时取消可取消的在途请求，清空等待队列，停止后台任务和通知。
已经发出的请求无法撤回；关闭后不能新建请求。保留其它偏好但不生效，
其中后台刷新与摘要通知的启用状态必须同时置为关闭；保留主题、时间等配置。
以后重新开启新闻只开启前台获取，后台刷新和通知需要用户再次明确开启。

### NET-02：只获取公共内容，在本地选择

数据流：已核实的公共新闻条目 → 本机缓存 → 本地词表匹配/排序 → 展示。
当前完整正文交给用户明确选择的外部浏览器打开；应用只获取 RSS 字段。
不把词表、复习计划、屏幕内容、个人向量或兴趣评分写进搜索词、URL 参数、
请求头或服务端账户。没有云端推荐/改写失败回退。

DR 仍会收到正常访问请求，可能看到 IP、访问时间和请求的文章 URL。
因此文案不能写“完全无数据离开电脑”或“绝对匿名”。
显式打开原文会交给浏览器联网访问，遵循浏览器自身的隐私设置，
不自动开启应用新闻后台功能。

### NET-03：频率、缓存与离线

试验参数：新闻页打开且缓存超过 30 分钟时获取一次；手动刷新至少相隔
60 秒；另行开启后台刷新后最多每 6 小时获取一次元数据，尊重更严格的来源限制。
缓存未过期时打开页签不重复联网。当前支持超时及 1 分钟至 6 小时指数退避；
未实现条件请求。后台不在用户正在浏览新闻页时抓取。
后台失败不弹窗，不为保持卡片数量高频重试。

候选内容最多展示 7 天或来源允许的更短时长。磁盘保存有界缓存，旧记录在后续更新中淘汰。关闭联网后仍可读未过期缓存及其
本机短版，标注“已缓存”与原始日期，不声称刚刚更新。
离线、限流或来源不可用时保留词条与阅读功能；清楚展示缓存状态，
用户可主动在浏览器打开原文。新闻卡片以原生文本渲染，不能嵌入会自动
加载第三方资源的页面来破坏零请求约束。

### NET-04：来源能力必须核实

目标来源已由用户确认是 **dr.dk**。2026-10-22 直接核实 DR 官方
[RSS 指引](https://www.dr.dk/nyheder/dr-nyheder-som-rss-feed)及实际 RSS HTTP 200 响应。
官方指引列出各主题订阅入口；实际条目可能只有标题、日期和链接，没有摘要。
能力记录见 `Resources/News/dr-source.json`；仅允许 RSS 字段及其本机摘要简化，
不把 RSS 可用解释为完整文章抓取、完整文章改写或再发布的概括授权。

维护来源能力记录：元数据入口、允许展示字段、缓存限制、正文获取、
本机改写支持范围、核实日期与依据。未知能力默认不启用。
来源失效/限制访问时不自动换第三方镜像或绕过限制；退化到已获准元数据和
原文入口，必要时显示“来源暂不可用”。DR 的联网接入是独立验收项，
不阻塞离线学习 policy 的实现。

## 6. 本机改写

### GEN-01：原文为默认，短版按需

直接阅读新闻是完整功能；短版是可选便利。使用已经安装的本地语言模型
处理文本（可使用现有 Gemma 的文本能力），不要求截图或视觉推理。
缺模型时保持原文/摘要可读，不自动安装，不切云服务。

只有来源允许、正文确实取得且文本提取完整时，才可改写该正文。
只有摘要时允许明确标注的“摘要简化”，不能用模型补成全文。
试验目标为 80–140 个丹麦语词，优先短句、清楚指代和自然表达。
篇幅不足时不扩写凑字数。读短版不要求先答题或补全。

### GEN-02：事实与可追溯性优先

每条短版保留原文链接、原始发布时间、取得时间、原文版本指纹和模型版本。
标题下固定标“本机 AI 简化 · 根据 DR 报道”，不把改写当 DR 原文。
原始标题保持来源文本；另写的说明不能冒充原标题。

人名、数字、日期、主体、否定、因果、归属及不确定性必须保留。
不制造引语，不把“被指控”改成“已经做了”，不把预测改成事实。
学习词只在语义自然且事实不变时使用，不能为了复习改写事件。

进行实体/数字/否定/归属等可检查项目的保守比对；比对通过不代表事实已获证明。
模型自我检查不能充当事实保证。缺关键信息、出现可疑改动或正文不完整时
不展示改写，退回可用原文/摘要并说明“短版未生成，可读原文”。
原文有实质更新时旧短版标为对应旧版本，不静默当作当前报道继续推荐。

### GEN-03：生成任务不得拖慢查词

推荐排序不调用大模型；先用本地词表、元数据和缓存。
新闻生成低优先级，单任务运行。存在安全抢占能力时才允许与阅读共存；
查词开始后必须让出资源或取消，先给已有本地翻译。
共享引擎无法可靠让出时，阅读期间不启动新闻生成，保留原文阅读并提示
“阅读暂停后可生成短版”；不能仅设置低进程优先级就宣称没有竞争。
本轮 policy 不给冷模型启动虚假的耗时保证。

## 7. 界面文案契约

以下是中文语义基准，客户端沿用现有界面语言并做等义本地化。
所有联网与改写标识在亮/暗主题、键盘导航和读屏中同样可识别。

| 位置 | 文案 |
| --- | --- |
| 主开关 | 新闻推荐（联网） |
| 开启说明 | 从 DR 获取新闻，推荐与可选改写在本机完成。不会上传词表、截图或学习记录；DR 会收到正常访问请求，包括 IP 等连接信息。 |
| 页签 | 读点新的 |
| 实际标题/摘要命中 | 标题/摘要包含你最近接触的：… |
| 无词匹配的兴趣推荐 | 你关注的主题：… |
| 内容操作 | 读原文（浏览器联网）／读短版（本机 AI）／少看这类／已看过 |
| 改写标识 | 本机 AI 简化 · 根据 DR 报道 · 查看原文 |
| 缓存 | 已缓存 · 原文发布于 … · 上次获取 … |
| 没有合适候选 | 暂时没有合适的新内容。可以换个主题，或稍后再看。 |
| 求助 | 查看释义／看整句意思／上次那句 |
| 阅读模式 | 自然融入／充分辅助 |

不使用“你已经学过，先想想”“完成复习解锁新闻”“今天还欠…”，
不把用户主动求助称为偷懒。推荐卡片不展示未经证明的掌握百分比。

## 8. 验证与跨平台交付

当前实现把相同输入交给共享原生策略，原生测试比较相同的辅助/联网/推荐决策。
通过 fake clock、虚构文章、预置文本及假网络适配器完成测试；不下载真实新闻、
不启动系统通知、不采集桌面、不播放声音。稳定用例放在
`Tests/Shared`，与现有语言行为契约一并执行。

关键验收：

- 主动查词与整句求助从不被练习拦截；焦点含义不隐藏。
- 新闻关闭零请求；启用新闻不隐式授权后台或推送；关闭立即阻止后续请求。
- 未接触过的义项不因词形相同丢失辅助。
- 新信息/兴趣门槛先于学习分数；同事件不会因多个词重复推荐。
- 低置信度或不完整来源不生成看似真实的完整报道。
- 任何新闻功能失败，不使查词、离线语音或词条管理不可用。

产品验证分别观察：新内容自愿打开/继续阅读、少看与已看反馈、辅助请求、
学习/新闻关闭率；有自愿参与者时再测隔天/隔周无提示回忆、新语境理解和产出。
点击率、读到末尾和词匹配率不替代学习结果；也不能以学习提高为理由容忍
明显的阅读流失。不监听外部 Google Translate 使用来推断流失，使用自愿访谈
或反馈；任何遥测需要独立设计与授权，本 policy 不引入遥测。

建议交付顺序：

1. 离线阅读兜底与求助语义，移除默认前置题/旧句任务。
2. 明确授权的新闻元数据、缓存、原文入口、本地推荐；先不依赖改写。
3. 来源核实与资源抢占验证完成后，加入按需短版。
4. 最后提供单独开启的每日摘要与可选练习。

在对应功能上线前更新 SECURITY、README 与平台指南的联网说明；
不能保留“应用没有网络能力”的绝对承诺再悄悄加 HTTP 客户端。

## 9. 研究依据与设计假设的区别

[Karpicke 与 Roediger（2008）](https://doi.org/10.1126/science.1152408)
支持重复提取对延迟记忆的作用，不证明“每次查词都应该先考试”。
[Cepeda 等（2008）](https://pubmed.ncbi.nlm.nih.gov/19076480/)
支持间隔安排与保持时长的关系，不证明本文件的 14 天、1 个词等试验参数。
[Chandy 等](https://doi.org/10.1017/S0142716424000407)
对重复阅读及语境变化的结果提示：熟悉旧句与新语境迁移需要分别检查。
“新信息提高使用积极性”和本文件的排序权重是待验证的产品假设，
不能当成已经证明能提高长期词汇掌握的结论。
